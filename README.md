# 🏡 Wanderlust – Airbnb Clone

A full-stack Airbnb-inspired web application built using Node.js, Express.js, MongoDB and EJS.

## 🌐 Live Demo

https://airbnb-clone-1-xsw0.onrender.com

## ✨ Features

* 🔐 User Authentication & Authorization
* 🏠 Create, Edit & Delete Listings
* 🖼️ Image Upload using Cloudinary
* ⭐ Reviews & Ratings
* 🗺️ Location & Map Integration
* 👤 Owner-based Listing Management

## 🛠️ Tech Stack

* HTML, CSS, JavaScript
* Bootstrap
* Node.js & Express.js
* EJS
* MongoDB & MongoDB Atlas
* Passport.js
* Cloudinary & Multer
* Leaflet & OpenStreetMap

## ⚙️ Installation

```bash
git clone https://github.com/sakshi7778/airbnb-clone.git
cd airbnb-clone
npm install
```

Start the application:

```bash
node app.js
```

For development:

```bash
npx nodemon app.js
```
